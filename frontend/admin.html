Language font and size (menu page)

Size change is added to every text size on the menu page for that language (in px, for example 2 = 2 px bigger, 0 = unchanged). Font "Default" keeps the built-in font for the language. Arabic starts at +2 px.

"This meal automatically includes" text

Shown in the dish pop-up, only for the dishes that are ticked "This dish is a meal" (Menu items). Leave a language empty to use the built-in text: "Seaweed Soup, Fried Egg Rice, Noodles, Salad & Water". To make some words bold, type two stars before and after them, for example **Seaweed Soup**.

Global dish text style

These name and price styles are applied to every menu item. You can still make individual changes in Menu items.

Category boxes: outline

The category boxes are the row at the top of the menu page (Beef Meal, Chicken Meal ...). Tick the box, choose any color and thickness. Untick it to go back to the normal thin grey line.

Bold text

Tick a text to make it bold. Untick it to make it normal. To make only some words bold, type two stars before and after them, for example **Seaweed Soup**. This works in the dish description (Menu items) and in the "This meal automatically includes" text above.

White card (name and price)

White card formatting includes its size, color, border, overlap, spacing, padding, and corners. The dish names, prices, and Add to cart styling are not copied.

Overall font copies the card-wide font and text scale (including English) to every other item. It does not copy the name or price-specific settings.

A bigger width makes the white card wider and leaves less room for the picture on the left. 67 = normal. Height 100 = the card covers the full height. Font sets the starting font for the name, price and Add to cart button. Size (100 = normal) scales the name and price; each language's name and price Size multiplies this scale. Border width 0 hides the line inside the card. Empty = the normal look.

Add to cart button

Size 100 = normal, 150 = one and a half times bigger. Plus numbers move the button right or down, minus numbers move it left or up. 0 = normal place (bottom corner).

Apply copies the Add to cart button's size, position, fill, text color, corner radius, and text size to every other menu item.

Background picture (the photo behind the dish)

Only the strip of the picture that is not covered by the white card can be seen. 100 = normal size, 50 = centered.

Apply copies only this background picture's size and position. Each menu item keeps its own background photo.
